# Music Visualizer v3 — GitHub Pages

브라우저에서 이미지와 음악을 불러와 실시간 음악 비주얼라이저를 미리 보고 영상을 추출하는 정적 웹앱입니다.

## 포함 기능
- 이미지 기반 흐림/색상 배경 자동 생성
- 이미지의 밝기와 배경에 따른 자동 텍스트 명암 조절
- 이미지에서 추출한 포인트 색상 자동 적용
- 앨범 이미지 앞 / LP 뒤 레이어 구성
- **원본 이미지 비율 보존** — 1080×1080에서도 이미지가 찌그러지지 않음
- 브라우저 내 음악 재생 및 일시정지
- 재생 위치 seek / 볼륨 조절
- 음악 진행에 따른 진행바와 LP 회전
- 실시간 오디오 주파수에 반응하는 파형
- 폰트 선택
- **제목 / 아티스트 / 설명 폰트 크기 조절**
- 1920×1080 / 1280×720 / 1080×1080
- 우측 상단 재생 시간 및 하단 진행 시간의 안전한 배치
- 하단 진행 시간 `현재 - 전체` 표시
- WebM 영상 추출
- MP4 MediaRecorder 지원 브라우저에서 MP4 추출, 미지원 브라우저에서는 WebM fallback

모든 파일 처리는 브라우저에서 이루어지며 서버에 이미지나 음악 파일을 업로드하지 않습니다.

## GitHub Pages
1. 저장소 루트에 `index.html`, `style.css`, `app.js`를 올립니다.
2. Settings → Pages → Source에서 `Deploy from a branch`를 선택합니다.
3. Branch는 `main`, 폴더는 `/(root)`로 지정합니다.
4. 저장 후 Pages 주소에서 앱을 엽니다.

## 참고
MP4 직접 녹화 가능 여부는 브라우저의 `MediaRecorder` 구현에 따라 달라집니다. MP4가 지원되지 않는 환경에서는 요청이 자동으로 WebM으로 저장됩니다.
