# Music Visualizer

브라우저에서 이미지와 음악을 이용해 음악 비주얼라이저를 만들고 로컬에서 영상을 추출하는 정적 웹앱입니다.

## 주요 기능
- 이미지/음악 로컬 선택
- 이미지 기반 색상 및 명암 자동 적용
- 실시간 음악 미리보기
- 미리보기 전용 탐색(재생) 바와 볼륨 조절
- LP 회전 및 오디오 반응형 파형
- 다양한 폰트
- 1920×1080 / 1280×720 / 1080×1080
- WebM 추출
- **MP4 추출: 브라우저에서 WebM을 생성한 뒤 FFmpeg WebAssembly로 H.264/AAC MP4로 변환**
- MP4는 `faststart` 옵션을 사용해 다운로드 후 재생 위치 탐색(seek)이 가능하도록 구성

## 개인정보
이미지와 음악은 서버로 업로드하지 않고 브라우저에서 처리합니다. MP4 변환에 필요한 FFmpeg WebAssembly 파일은 CDN에서 브라우저로 로드됩니다.

## GitHub Pages
`index.html`, `style.css`, `app.js`를 저장소 루트에 올리고 GitHub Pages에서 `main` 브랜치의 root를 배포 소스로 사용하면 됩니다.

## MP4 변환 참고
MP4 추출을 처음 실행하면 FFmpeg WebAssembly 코어를 CDN에서 내려받기 때문에 시간이 조금 걸릴 수 있습니다. 변환은 사용자의 브라우저에서 수행됩니다.
